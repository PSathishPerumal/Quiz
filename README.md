# 🧠 Quiz Application

A simple and interactive **Quiz App** built with **HTML**, **CSS**, and **JavaScript**. This project allows users to answer multiple-choice questions, view instant feedback, and track their scores in real time.

---

## 📋 Features

- Multiple-choice questions
- Real-time score tracking
- Immediate feedback on answers
- Restart quiz functionality
- Responsive and user-friendly UI

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the quiz interface
- **CSS3** – Styling and layout
- **JavaScript (ES6)** – Quiz logic, question handling, and score management

---

## 📂 Project Structure

quiz-app/
├── index.html # Main HTML file
├── style.css # Styling for the quiz UI
└── script.js # JavaScript for quiz logic
